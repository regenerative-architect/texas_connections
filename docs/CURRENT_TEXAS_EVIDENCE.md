# Current Texas Evidence Snapshot

As-of/retrieval date: 2026-09-28.

The application ships a curated machine-readable source register in `data/texas-current.json`. It includes official-source snapshots for Texas BEAD, BOOT, Middle Mile, Pole Replacement, broadband workforce, E-Rate/state match, rural hospitals, public libraries/LIFI, digital opportunity, TAP, FCC/BDO maps and related institutional connectivity programs.

Program status changes. The in-app record is a dated snapshot, not an entitlement or live eligibility determination. Follow the official source link before making a grant, procurement, engineering or compliance decision.
