# Multidisciplinary Collaboration Protocol

This release adds a typed collaboration layer for families, institutions, governments, corporations, educational bodies, businesses, health systems, libraries, utilities, workforce organizations, nonprofits, emergency management and researchers.

## Shared lifecycle

Observed → validated → designed → funded → building → operational → adopted → verified.

Do not collapse these stages. An announcement, selection or award is not evidence that a location is operational.

## Handoffs

A handoff contains: from-domain, to-domain, requested contribution, owner/organization, due date, status, privacy class and evidence/context references. Handoffs synchronize through the same Trystero/WebRTC event channel as tasks and decisions and are included in peer snapshots.

## Data boundary

The P2P commons is a coordination layer, not an approved repository for regulated confidential records. Share the minimum necessary data. Use references or aggregates when source records must remain in institutional systems.

## Identity boundary

Display names, roles and Trystero peer IDs are not verified human or organizational identities. Organizations needing authenticated membership must add an approved identity/admission layer rather than treating presence labels as proof.
